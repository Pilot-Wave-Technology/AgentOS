Install steps

  1. Install the coding CLI — Claude Code (recommended) or Codex — and make sure it's on your PATH.
  2. Click Download .vsix above.
  3. In VS Code: Extensions view → ⋯ menu → Install from VSIX… → pick the file → Reload Window.
  4. The Get started walkthrough opens: set the control plane URL to the value above, sign in, and confirm the CLI. Your stories then appear in the sidebar.
  5. Updates are automatic — the extension checks this deployment daily and prompts you to download & reinstall the newer .vsix.

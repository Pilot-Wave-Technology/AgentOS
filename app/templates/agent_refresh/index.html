Refresh Agents

Push the current AGENTS.md, SOUL.md, tools and skills to agents that already exist. Memory and conversations are preserved.

{# The one thing somebody has to understand before pressing the button, so it is above the button and not in a tooltip. #}
Prompts do not go live until the gateway restarts.

The gateway caches each agent's prompt files per session, so a pushed AGENTS.md is invisible to a running conversation. A restart clears that cache and keeps every conversation — sessions live on disk and rehydrate. sessions.reset would also clear it, but it ends the conversation, which is why this tool never uses it.

Tools and skills go live immediately, so apply and restart in the same quiet window — the prompt is what names the tools, and a tool renamed while its prompt still teaches the old name means every call is refused.
